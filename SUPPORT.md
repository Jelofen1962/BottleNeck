# Support

Start with the [user handbook](HANDBOOK.md) or the [deployment guide](docs/DEPLOYMENT.md). The handbook covers day-to-day work; deployment docs cover installation, upgrades, storage and backups.

For a reproducible bug, open an issue with the BottleNeck version, operating system, installation method and the steps that trigger the problem. Remove email addresses, invitation tokens, session cookies and private workspace content from logs before attaching them.

For feature ideas, use the issue tracker or repository discussions. For security reports, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
